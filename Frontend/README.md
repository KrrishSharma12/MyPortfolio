# Krish Sharma – Portfolio (React + Vite)

    npm install
    npm run dev       # local dev server
    npm run build     # production build in /dist

- Edit content in `src/data.js` (links, skills, projects, journey).
- Resume: put your PDF at `public/resume.pdf`.
- Contact form: copy `.env.example` to `.env` and set `VITE_CONTACT_ENDPOINT` (Formspree / Web3Forms / your API). Without it, the form opens your email app.
- Project screenshots: import an image in `src/data.js` and add `image: yourImport` to the project.
